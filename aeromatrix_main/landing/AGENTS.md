# Notes for coding agents (landing/)

- This is a separate package (`tanstack_start_ts`) from the web app in the parent folder. Install and run it from here.
- TanStack Start with file routes: `src/routes/__root.tsx` and `src/routes/index.tsx`. `src/routeTree.gen.ts` is generated by the
  Vite plugin on dev/build; do not edit it by hand.
- Import with the `@/` alias (`src/`). Styling is Tailwind 4 with tokens in `src/styles.css` (`cherry-*`, `cream-*`). Reuse them.
- Page copy must only claim what the product does. Do not add statistics, accuracy figures, counts or testimonials.
- Images are optional slots in `src/assets/*.jpg` read through `import.meta.glob`; every slot needs a drawn fallback in
  `ImageSlot.tsx`. Do not add the seven image files to the repository on your own; they are supplied by the owner.
- Links into the web app go through `src/lib/links.ts` (`APP_URL`, `deepLink`). Do not hard-code `localhost:5173` elsewhere.
- Motion must respect `prefers-reduced-motion`, and content must stay readable without JavaScript.
- Before finishing: `npm run typecheck` and `npm run build`, with and without images in `src/assets`.
