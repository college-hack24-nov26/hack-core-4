# App features

- Launcher: a round button at the bottom left opens Overview, Air Quality, Zones, Industries, Actions, What-If, Sites and Sensors.
- Air Quality: Now (model data), Monitoring stations, Forecast and the rule model.
- Display modes: Baseline, Scenario, Change, Current (Open-Meteo), Observed (imported CSV) and Forecast (trained model).
- Data panel: import CPCB or weather CSV files in the browser, see model against observed statistics and calibrate the prototype model.
- Industries: MIDC estates and mapped industry sites; reduce, shut down or relocate the modeled sources nearby.
- Plan-It: budget-constrained plans with a PDF.
- Sensors: next-hour PM2.5 and PM10 replays for a station whose sensor is off.
- AeroSage: this assistant. It reads numbers from the model API and Open-Meteo, explains the project, and can open sections, select regions and change simulator settings.
- Deep links: the address can name a section, for example the analytics or sensors section.
